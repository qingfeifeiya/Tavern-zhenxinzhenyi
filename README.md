# 甄心甄意·衣柜 (Zhenxin Wardrobe)

**甄心甄意·衣柜**是一款运行在 SillyTavern（酒馆）中的沉浸式服饰管理与智能穿搭脚本。它基于「酒馆助手 (TavernHelper)」运行，提供从**单品收集、全身槽位搭配、AI 多模态识图描写**，到**随剧情发展自动同步穿脱与选衣注入**的完整体验。

> **当前状态**：项目处于活跃开发阶段，尚未发布正式发行版，可直接复制仓库中的开发版源码体验全部功能。

---

## 核心特性

* **多衣柜与单品画廊**
  * 支持创建多个独立衣柜与跨柜「组合衣柜」，按 `USER 玩家`、`Char 角色` 或 `双人通用` 分视图管理。
  * 支持正背面双视图（本地上传、外链、拖拽或 `Ctrl+V` 直接粘贴建卡）、尺度分级（`SFW` / `R-15` / `R-18`）、分类、穿戴部位与 `#标签` 检索。
* **全身搭配台与套装自动拆分**
  * 默认提供 8 个全身穿戴槽位（支持自定义增删与改名），可跨衣柜挑选单品组装套装，自动汇总部位描写。
  * 支持识别整套描述中的 `【上装】`、`【下装】` 等部位标签，一键将整套服饰拆分为关联的部位子卡，也可随时撤销拆分。
* **AI 视觉工坊（多模态识图与扩写）**
  * 内置 **整套衣服描述生成**、**单品衣服描述生成**、**MOSS 中文生图提示词增强**、**NovelAI / SD 英文视觉特征 Tags** 四种生成预设。
  * 支持携带参考图进行多模态识图，生成的结构化 JSON 可在预览确认后，随保存自动回填标题、分类、穿戴部位、标签、分级与描写。
* **沉浸式聊天穿搭与自动选衣**
  * **手动搭配模式**：直接将全身搭配台的当前草稿（文字、参考图或尺度分级）注入聊天上下文。
  * **额外 API 自动选衣**：先核对近期聊天正文里**实际发生的穿脱变化**（含原文引用校验），再结合角色设定、世界书绑定与场合从候选池智能换装。
* **安全存档、主题定制与诊断日志**
  * 采用串行事务队列与写回校验保护酒馆存档，自动清理无引用的本地孤儿图片，支持 `JSON` 与 `ZIP` 数据包（含可选 WebP 压缩与重复项比对）迁移。
  * 内置深浅双基底调色盘与脱敏诊断日志，方便定制外观与排查接口问题。

## 安装与打开

1. **启用前置扩展**：在 SillyTavern 中安装并启用「酒馆助手 (JS-Slash-Runner)」。具体方法参见[酒馆助手脚本库文档](https://n0vi028.github.io/JS-Slash-Runner-Doc/guide/%E5%9F%BA%E6%9C%AC%E7%94%A8%E6%B3%95/%E8%84%9A%E6%9C%AC%E5%BA%93.html)。
2. **导入衣柜脚本**：打开本仓库的 [`index.js`](./index.js) 并复制完整源码。进入酒馆助手的「全局脚本库」，新建脚本、粘贴源码、保存并启用。
3. **打开衣柜面板**：
   * **方式一（悬浮球）**：点击画面左侧的衣架悬浮球，选择「打开衣柜面板」（悬浮球支持按住拖拽位置，也可在菜单中一键开关插件功能）。
   * **方式二（扩展菜单）**：点击酒馆输入框旁的魔法棒图标（扩展菜单），选择「衣柜面板」。

## 功能速览

| 模块 | 主要能力 | 常用操作 |
| :--- | :--- | :--- |
| **单品画廊** | 管理全库单品与套装卡片，支持分类、穿戴部位、分级与标签筛选 | 按 `Ctrl+K` / `⌘K` 全局搜索；在画廊空白处按 `Ctrl+V` 直接粘贴剪贴板图片新建服饰 |
| **全身搭配台** | 在 8+N 个身体槽位中混搭单品，实时生成套装描述与已穿清单 | 点击槽位跨衣柜选衣，点击「保存/修改」存为可复用的套装卡片 |
| **AI 视觉工坊** | 根据参考图与现有资料生成客观结构描写、尺度分级依据及生图词 | 在单品详情或搭配台切到「2. AI 视觉工坊」，点击「一键生成」后点保存自动分栏 |
| **世界书与人物绑定** | 限制特定服饰仅在指定人物或指定世界书激活时进入自动选衣候选池 | 在单品详情切到「3. 世界书绑定」，开启绑定开关或添加 `@人物名称` |
| **聊天穿搭注入** | 将当前穿搭描述、参考图与尺度分级按自定义角色模板注入主聊天 | 在「设置 → 发送内容 / 角色模板」配置注入位置、内容类型与变量模板 |
| **数据包导入导出** | 按衣柜或整理状态打包迁移服饰与图片，支持重复服饰冲突处理 | 点击顶栏「导入 / 导出」，选择导出 `JSON` / `ZIP`（可勾选压缩图片） |

## 模型与发送配置

日常浏览、录入服饰、手动拼搭套装与导入导出数据包**无需配置 API 即可直接使用**。

### 1. 配置 AI 视觉工坊与选衣接口
若需使用「AI 视觉工坊」或「额外 API 选装」，请点击顶栏 **「设置 → API」**：
1. 选择连接方式：
   * **酒馆主 API**：直接复用酒馆当前主连接（需确保酒馆主连接处于「聊天补全 / Chat Completion」模式）。
   * **自定义**：填写兼容 OpenAI 格式的接口地址（如 `https://api.openai.com/v1`）、接口密钥与模型名称（可点击「加载模型」拉取列表）。自定义密钥保存在当前标签页会话中。
   * **酒馆预设**：直接调用酒馆 Connection Manager（连接管理器）中已保存的聊天补全预设，无需切换酒馆主连接。
2. 点击右下角 **「保存当前预设」**（可通过星标按钮指定默认预设）。
3. **多模态识图提示**：若勾选了「连同服饰参考图一起多模态识图」或使用图片选衣，所选模型需具备视觉（Vision）图片输入能力。

### 2. 配置主聊天穿搭发送
点击顶栏 **「设置 → 发送内容」** 配置聊天时的运作方式：
* **手动搭配模式（默认）**：「额外 API」设为 **「关闭」**。此时在单人聊天发送消息时，脚本会直接读取「全身搭配台」里当前的草稿并注入上下文，无需先保存成卡片。
* **智能自动选衣**：「额外 API」设为 **「额外 API 选装」**，设置读取前文楼层数（默认 12 楼）与选衣提示词，最后点击底部 **「保存设置」**。
* **发送带图提示**：当「发送给 AI 的内容类型」设为「仅图片」或「文字＋图片」时，酒馆主连接需为支持图片输入的聊天补全接口。
